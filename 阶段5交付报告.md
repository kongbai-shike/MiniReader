## 二、`spread.py` 的四条规则

规格里最容易做错的四处，全部收在这一个纯函数模块里，逐条都有实测依据：

### 2.1 配对：封面单独时锚点**不是**偶数序列

```
cover_alone=True   ->  [0] [1,2] [3,4] [5]     锚点 0,1,3,5…
cover_alone=False  ->  [0,1] [2,3] [4,5]       锚点 0,2,4…
```

第一版实现想当然地让"每个锚点配 `anchor+1`"，于是 `spread_at(0, 6, True)` 返回
`(0, 1)` —— **封面和第一页挤在了一起**，而 `(1, 2)` 那一跨页根本不存在。
纯函数的穷举测试立刻抓到：`total` 从 0 到 24 逐个验证"每一页恰好出现在一个跨页里"。

实测：`spread_starts(6, True) == [0, 1, 3, 5]`，`spread_starts(6, False) == [0, 2, 4]`，
`spread_at(0, 6, True) == (0, None)`，`spread_at(2, 6, True) == (1, 2)`。

### 2.2 装订方向：靠**对调槽位**，不靠镜像

rtl（右綴じ，日漫）小页码在右，ltr（左綴じ）在左。实现只有一句：

```python
return (second, first) if right_to_left else (first, second)
```

`PageView` 完全不知道方向，布局也不知道——它只知道"左槽、右槽"。这样换方向就是
一次重新摆放，没有第二处需要同步的状态。

落单页（封面单独、或末页落单）占**起始边**：rtl 占右槽，ltr 占左槽。规格原文
说的是"最后一页若落单，rtl 时放右侧"，而同一个规则恰好也适用于封面，所以只用
一条规则覆盖两种情况，阅读顺序因此始终连续——跨页总是从阅读方向的起始边开始。

实测：`visual_order((1,2),'rtl') == (2,1)`，`visual_order((1,2),'ltr') == (1,2)`，
`visual_order((0,None),'rtl') == (None,0)`。

### 2.3 共享高度：接缝水平的唯一保证

两页各自宽度适应会让不同形状的两页高度不同，接缝就是锯齿状——这是双页视图
看起来"坏掉"的典型样子。`pair_size()` 取**一个**高度给两页，宽度按各自宽高比推出：

```
高度 = min( 视口高, (视口宽 - 间距) / Σ(宽/高), 最小源高 )
```

三个约束同时满足：放得下、不溢出、**不放大**（和 `fit_size()` 同一个承诺）。
实测两页 600×900 在 1200×720 视口里：`pair_size → (720, [480, 480])`。

复核时又用**真 widget** 量了一遍（`SpreadView.resize(1200,720)`，两页都是 600×900）：

```
viewport 1200x720:
   left : x=  80 w= 480 h= 720
   right: x= 640 w= 480 h= 720
   left margin = 80 | right margin = 80
```

两槽 x 坐标 80 与 640，各 480 宽、720 高，左右各留 80 px 居中——和 §2.3 的算术
完全对得上，也与 §七 手动确认第 4 条一致。

### 2.4 触发阈值：840 不算宽，841 才算

`width > height × 1.4`，实测边界精确：600 高的窗口宽 840 不进双页，841 进。
高度为 0（还没布局）判为"不够宽"——进模式 C 太早会显示两个空条，而且除了模式
按钮没有别的退路。

## 三、探针抓到的缺陷（都已修，都有回归测试）

### 缺陷 1：末页跨页报出"第 40-41/40 页"

**症状**：40 页的书翻到最后一跨页，底栏写"第 40-41/40 页"——**一个不存在的页**。

**根因**：`Position.label` 直接拼 `index + span`，没有夹到 `total`。落单的末页
（或单独显示的封面）因此多报一页。

**修法**：`last = min(index + span, total)`，且当 `last <= index + 1` 时退回单页
形式——那本来就是事实（屏幕上只有一页）。

**回归**：`TestPositionLabelSpan::test_the_range_never_runs_past_the_book`

### 缺陷 2：按"下一页"两次停在同一个跨页上

**症状**：从封面起连按 4 次"下一页"，只走到第 3 个跨页；`chapter_index` 一直在
涨，而屏幕上不动。

**根因**：`step_chapter()` 做的是 `chapter_index + delta`——**加一页**。模式 C 里
一跨页是两页，reader 收到这个页码后又把它塌回它所属的跨页，于是两页的位移只
换了一次跨页。

```
step 0: index=0 pair=(0, None)
step 1: index=1 pair=(1, 2)
step 2: index=1 pair=(1, 2)   <- chapter_index=2，但屏幕上还是 (1,2)
step 3: index=3 pair=(3, 4)
```

**修法**：模式 C 的步长交给 reader（`next_page()`/`prev_page()` 懂跨页算术），
窗口只采纳落点。窗口那一层不该懂"跨页"这个概念。

**回归**：`TestWindowSpreadMode::test_a_spread_turn_moves_two_pages`（断言连按三次
得到 `(1,2) (3,4) (5,6)`）

### 缺陷 3：`MODE_PENDING` 的死引用（本次磁盘复核查出）

这一条**不是**上一轮写的，是这次复核读代码时发现的，也是本次唯一改动的生产代码。

**症状**：`comic_reader.py` 的 `set_mode()` 里留着

```python
        if mode not in IMPLEMENTED_MODES:
            self.notice.emit(MODE_PENDING.get(mode, "这个阅读模式还没做"))
            return
```

而 `MODE_PENDING` 这个常量**已经按本阶段的设计被整个删掉**了。实测：

```
>>> hasattr(comic_reader, 'MODE_PENDING')
False
>>> IMPLEMENTED_MODES, READING_MODES
('single', 'scroll', 'spread') ('single', 'scroll', 'spread')
>>> set(READING_MODES) - set(IMPLEMENTED_MODES)
set()
```

**为什么测试没抓到**：这条分支**不可达**——`IMPLEMENTED_MODES` 已经覆盖了
`READING_MODES` 全集，所以 `mode not in IMPLEMENTED_MODES` 永远为假，那行永远
不会执行。守着它的两条测试（`test_asking_for_an_unimplemented_mode_says_so`、
`test_a_pending_mode_still_announces_itself_when_asked_directly`）都在
`pending` 为空时 `skipTest`，所以它们给出的是**假安心**：既有测试断言
`MODE_PENDING` 不存在，又有一行代码在引用它，两边都没红。

**危害**：将来某个阶段往 `READING_MODES` 加一个模式、却还没实现它时，这行会
立刻变成 `NameError` ——而且是在"用户点了一个还没做的模式"这条路上崩。

**修法**：删掉对已删常量的引用，改用一个通用文案。

```python
        if mode not in IMPLEMENTED_MODES:
            # A generic sentence on purpose. `MODE_PENDING` used to carry a
            # per-mode "coming in stage N" wording, and stage 5 deleted it once
            # all three modes landed - so there is no table left to look the
            # sentence up in. Leaving a reference to it here was a latent
            # `NameError`: unreachable while `IMPLEMENTED_MODES` covers
            # `READING_MODES`, but armed the moment a future phase adds a mode
            # without implementing it. The exact sentence belongs to the phase
            # that ships the mode; until then any non-empty explanation will do.
            self.notice.emit("这个阅读模式还没做")
            return
```

**验证**：把 `READING_MODES` 临时扩成含一个未实现模式，再问它——修之前是
`NameError`，修之后正常拒绝并给出提示：

```
READING_MODES = ('single','scroll','spread','webtoon')
set_mode('webtoon')  ->  mode 仍是 'single'，notice = '这个阅读模式还没做'
```

**为什么没有新增测试**：这条分支在当前版本里**按定义不可达**（没有任何模式未
实现），能测的只有"将来加新模式时"的假设情形。两条 skip 的测试已经覆盖了那个
情形的**行为契约**（拒绝 + 必须给非空解释），本次修的是它们覆盖不到的**实现**
（常量已被删）。把 `READING_MODES` 临时改掉再断言，属于给不存在的状态写测试，
会变成一个永远绿的假测试——所以只记录在案，不假装有回归。

### 一个"看起来是缺陷、其实是我测试写错"的插曲

`SpreadView._relayout()` 的高度一度不随视口变化（实测钉死在 800）。查下去发现
两个原因叠加，**都不是产品缺陷**：

1. **夹具没探尺寸**。`open_book()` 之后 `ComicPage.width/height` 还是 0，`SpreadView`
   对"尺寸未知"走的是另一条回退分支（每页半宽、视口高），那条分支本来就不随视口
   变。测试必须先 `set_page_size()`。
2. **布局的 stretch 覆盖了固定尺寸**。槽位用 `addWidget(slot, 1)` 加了 stretch，
   而 `setFixedHeight(300)` 会被 stretch 分配剩余高度时盖掉（`minimumHeight` 和
   `maximumHeight` 都还是 800）。改成 stretch 0 + `Preferred` 策略。

第 2 条是真代码问题（虽然只在测试的视口尺寸下显形），已经改掉并写进注释。
复核时用真 widget 复量，确认现在 `setFixedHeight` 生效：两槽都是 720 高。

## 四、模式 C 的实现要点

### 4.1 结构

```
ComicReader(Reader, QWidget)
  └── _stack: QStackedWidget
        ├── _page_view: PageView      <- 模式 A
        ├── _strip: StripView         <- 模式 B
        └── _spread: SpreadView       <- 模式 C（本阶段）
```

三个视图**构造时就建好、全程存活**，理由和前两个阶段一致：重建要重接信号，
漏一处就是静默的行为退化。

### 4.2 竖屏守卫放在 reader 里，不放在调用方

`set_mode("spread")` 自己检查 `width > height × 1.4`，不够宽就拒绝并 emit
「窗口太窄，已切回单页」。放在 reader 里而不是按钮里，是为了让**每一个**调用方
都得到同一个答案：模式按钮、设置对话框、开机恢复的偏好、`progress.json` 里存的
模式。

`resizeEvent` 也做同一件事：用户可以把横屏窗口拖窄，那时必须自己退出来。

### 4.3 封面判型：两条正信号，否则听设置的

| 顺序 | 规则 | 结果 |
|---|---|---|
| 1 | 文件名含 `cover` / `封面` / `000` | 单独显示（**压过设置**） |
| 2 | 前三页都是竖版（h > w） | 单独显示（**压过设置**） |
| 3 | 都不命中 | 用 `comic_cover_alone` 设置 |

"宁可问用户也不猜错"体现在第 3 条：只有两条**正**信号才自动判定，否则一律回落到
用户设置，绝不在没把握时替用户做决定。

实测：8 页竖版 + 默认开关 → 封面单独；横版书 + 关掉开关 → 首页就配对 `(0, 1)`；
`cover.jpg` + 关掉开关 → 仍然单独（规则 1 压过设置）。

### 4.4 进度

`Position(span=2)` → 「第 2-3/8 页」；落单页 `span=1` → 「第 1/8 页」。
`Progress.page` 存**跨页的第一页**，所以重开回到同一个跨页。

### 4.5 与现有功能的交互

| 交互 | 结果 |
|---|---|
| `set_mode("spread")` | 切进模式 C（竖屏被拒 + 提示） |
| `set_mode("single")` / `set_mode("scroll")` | 页码保持，不崩 |
| `IMPLEMENTED_MODES` | `("single", "scroll", "spread")`，`MODE_PENDING` 已删除 |
| 模式 C 下 `toggle_autoscroll()` | 不可用（`scrollbar()` 返回 None，既有闸门拦下） |
| 模式 C 下 wheel | 翻一跨页（走 `_step`，模式 C 分支） |
| 模式 C 下右键「上一页/下一页」 | 翻一跨页，边界处给提示 |
| `comic_binding` / `comic_cover_alone` | 阶段 4 已能存能读，本阶段是第一个消费者 |
| `comic_gutter` | **本阶段新增**的设置（0-32 px） |
| 进度持久化 | `Progress.page` 是跨页第一页 |

### 12.1 新增：`minireader/ui/spread.py`（全文 278 行）

```python
"""Two-page spread arithmetic (mode C), as pure functions.

Everything here is arithmetic on page sizes and page counts - no Qt, no widgets,
no book. That is deliberate: the rules below are the part most likely to be got
subtly wrong (which page goes on which side, where a lone page lands, how two
pages of different shapes share one height), and pure functions can be tested
exhaustively without a QApplication. `ComicReader` only calls them.

Four rules, and why each is what it is:

**A spread is a pair, and the cover may stand alone.** With `cover_alone` the
sequence is ``[0]``, ``[1, 2]``, ``[3, 4]``, ... - the shape a printed manga has.
Without it, ``[0, 1]``, ``[2, 3]``, ... The anchors therefore are *not* simply
even numbers when the cover stands alone (they are 0, 1, 3, 5, ...), which is why
`spread_starts()` exists rather than callers doing ``range(0, n, 2)``.

**Right-binding (rtl) puts the lower page number on the right.** Japanese manga
is read right to left, so within a pair page 1 sits to the right of page 2. This
is implemented by *swapping the two widgets' order* in the row, not by mirroring
anything: the layout is the only thing that knows about direction, so the page
widgets themselves stay direction-agnostic.

**A lone page takes the leading slot.** In rtl the leading slot is the right one,
in ltr the left one. This covers both the cover (when it stands alone) and an odd
final page, and using one rule for both is what keeps the reading order
continuous: a spread always *begins* at the leading edge.

**Two pages share one height.** Sizing each page width-fit would make a pair of
differently-shaped pages different heights, so the seam between them would be
ragged - the thing that makes a two-page view look broken. `pair_size()` picks a
single height for the pair instead, then derives each width from it.

Deliberately Qt-free, like `minireader.core.*`.
"""

from __future__ import annotations

#: The window must be at least this many times wider than tall before two pages
#: fit side by side without each being a useless sliver. A portrait (or square)
#: window falls back to single-page mode.
SPREAD_ASPECT = 1.4

#: Default gap between the two pages, in pixels. Zero because scanned manga
#: already carries its own margin; the setting exists for scans that were cropped
#: to the edge, where the two pages would otherwise touch.
DEFAULT_GUTTER = 0

#: `comic_gutter` is clamped to this, matching `storage.Settings.clamp()`.
MAX_GUTTER = 32

#: Substrings that mark a page as a cover. Matched case-folded against the page's
#: display name. "000" catches the very common `000.jpg` / `0001.png` scan naming,
#: where the zero-padded first page is the cover.
COVER_MARKERS = ("cover", "封面", "000")


def _fold(text: str) -> str:
    return str(text or "").casefold()


def name_says_cover(name: str) -> bool:
    """True when a page's file name announces itself as a cover."""
    folded = _fold(name)
    return any(marker in folded for marker in COVER_MARKERS)


def looks_like_a_cover(book, default: bool = True) -> bool:
    """Whether page 1 should stand alone in two-page mode.

    The spec's conservative order, and the reason it is conservative: showing a
    real story page alone throws off every later pairing, so a wrong guess is
    much worse than not guessing. Two positive signals only, then the user's
    setting:

    1. The first page's *name* says cover / 封面 / 000.
    2. The first three pages are all portrait. A cover standing alone in a
       portrait book is the standard shape; in a landscape (wide) book the first
       page is usually already a proper spread, so pairing is right.

    Returns `default` when neither signal fires - i.e. the setting is the answer,
    and the reader never overrides the user on a hunch.
    """
    pages = list(getattr(book, "pages", []) or [])
    if not pages:
        return bool(default)
    if name_says_cover(getattr(pages[0], "name", "")):
        return True
    if len(pages) >= 3:
        first_three = pages[:3]
        if all(_is_portrait(page) for page in first_three):
            return True
    return bool(default)


def _is_portrait(page) -> bool:
    width = max(0, int(getattr(page, "width", 0) or 0))
    height = max(0, int(getattr(page, "height", 0) or 0))
    return height > width > 0


def spread_starts(total: int, cover_alone: bool) -> list[int]:
    """The first page index of every spread, in reading order.

    ``total=6, cover_alone=True``  -> ``[0, 1, 3, 5]``   (``[0] [1,2] [3,4] [5]``)
    ``total=6, cover_alone=False`` -> ``[0, 2, 4]``      (``[0,1] [2,3] [4,5]``)

    Note the odd final anchor in the first example: with six pages and a lone
    cover, page 5 is left over and gets a spread to itself.
    """
    total = max(0, int(total))
    if total <= 0:
        return []
    if cover_alone:
        starts = [0]
        index = 1
        while index < total:
            starts.append(index)
            index += 2
        return starts
    return list(range(0, total, 2))


def spread_at(index: int, total: int, cover_alone: bool) -> tuple[int, int | None]:
    """The pages shown when the spread *containing* `index` is on screen.

    Returns ``(first, second_or_None)``. The caller may pass any page number, not
    just an anchor: `index=2` with `cover_alone=True` resolves to the ``(1, 2)``
    spread, so a saved position always lands on a spread that contains it.

    ``second is None`` means the page stands alone. That happens in two different
    situations, and both must be handled here rather than by the caller:

    * **the cover**, when `cover_alone` is set - anchor 0 is a singleton, and the
      pairing only starts at anchor 1 (``[0] [1,2] [3,4]``);
    * **an odd final page** - the last anchor is `total - 1` and `anchor + 1`
      runs off the end.
    """
    total = max(0, int(total))
    if total <= 0:
        return (0, None)
    index = max(0, min(int(index), total - 1))
    # Walk forward to the last anchor that is <= index. That anchor is the spread
    # containing `index`, because the anchors are strictly increasing and each
    # spread runs from its anchor to the next one.
    anchor = 0
    for start in spread_starts(total, cover_alone):
        if start <= index:
            anchor = start
        else:
            break
    if cover_alone and anchor == 0:
        # The cover stands alone; pairing begins at anchor 1.
        return (0, None)
    second = anchor + 1
    return (anchor, second if second < total else None)


def anchor_of(index: int, total: int, cover_alone: bool) -> int:
    """The first page index of the spread containing `index`."""
    return spread_at(index, total, cover_alone)[0]


def next_anchor(index: int, total: int, cover_alone: bool, delta: int) -> int:
    """The anchor `delta` spreads away from the one containing `index`.

    Clamped to the first/last spread, so the caller can compare the result with
    the current anchor to detect "already at the end" and say so.
    """
    starts = spread_starts(total, cover_alone)
    if not starts:
        return 0
    current = anchor_of(index, total, cover_alone)
    try:
        position = starts.index(current)
    except ValueError:  # pragma: no cover - anchor_of only returns real anchors
        position = 0
    target = max(0, min(position + int(delta), len(starts) - 1))
    return starts[target]


def is_last_spread(index: int, total: int, cover_alone: bool) -> bool:
    starts = spread_starts(total, cover_alone)
    if not starts:
        return True
    return anchor_of(index, total, cover_alone) >= starts[-1]


def is_first_spread(index: int, total: int, cover_alone: bool) -> bool:
    starts = spread_starts(total, cover_alone)
    if not starts:
        return True
    return anchor_of(index, total, cover_alone) <= starts[0]


def visual_order(pair: tuple[int, int | None], binding: str) -> tuple[int | None, int | None]:
    """`(left_page, right_page)` for a spread, honouring the binding.

    rtl (右綴じ, Japanese): the lower page number is on the **right**, so the pair
    is swapped. ltr (左綴じ): the lower number is on the left, i.e. unchanged.

    A lone page (`second is None`) goes to the leading slot: right for rtl, left
    for ltr. The trailing slot is None.
    """
    first, second = pair
    right_to_left = str(binding).lower() != "ltr"
    if second is None:
        return (None, first) if right_to_left else (first, None)
    return (second, first) if right_to_left else (first, second)


def pair_size(
    sizes: list[tuple[int, int]],
    viewport: tuple[int, int],
    gutter: int = DEFAULT_GUTTER,
) -> tuple[int, list[int]]:
    """A shared height and each page's width, so the seam between them is level.

    `sizes` is one or two `(width, height)` pairs. Returns
    ``(height, [width, ...])`` in the order given.

    The height is the largest one that satisfies all three constraints at once:

    * it fits the viewport's height;
    * the pages side by side plus the gutter fit the viewport's width;
    * it never exceeds the smallest source height - the project never enlarges a
      page (`comic_cache.fit_size()` makes the same promise for one page, and
      blowing up a scan only makes it blurry).

    A page with an unknown size `(0, 0)` is given the height of the other one
    (or the viewport's height when both are unknown) and a width of zero, which
    the caller renders as an empty slot rather than as a zero-width page.
    """
    view_w = max(0, int(viewport[0]))
    view_h = max(0, int(viewport[1]))
    gap = max(0, int(gutter))
    clean: list[tuple[int, int]] = []
    for size in sizes:
        width = max(0, int(size[0]))
        height = max(0, int(size[1]))
        clean.append((width, height))

    known = [(w, h) for w, h in clean if w > 0 and h > 0]
    if not known:
        return (view_h, [0 for _ in clean])

    # Constraint 2: widths add up. Each page's width is height * (w/h), so the
    # total width scales linearly with the height - one division gives the cap.
    ratios = [w / h for w, h in known]
    height = float(view_h)
    total_ratio = sum(ratios)
    if total_ratio > 0 and view_w > 0:
        width_cap = max(0, view_w - gap * max(0, len(clean) - 1))
        height = min(height, width_cap / total_ratio)
    # Constraint 3: never enlarge.
    height = min(height, float(min(h for _w, h in known)))
    height = max(1.0, height)

    widths: list[int] = []
    for width, source_h in clean:
        if width <= 0 or source_h <= 0:
            widths.append(0)
        else:
            widths.append(max(1, int(round(height * width / source_h))))
    return (max(1, int(round(height))), widths)


def needs_spread_width(width: int, height: int, ratio: float = SPREAD_ASPECT) -> bool:
    """True when the reading area is wide enough for two pages.

    Pure so the trigger can be tested without resizing a window. A degenerate
    height (0) is treated as "not wide enough": the answer must not depend on a
    not-yet-laid-out widget.
    """
    width = max(0, int(width))
    height = max(0, int(height))
    if height <= 0:
        return False
    return width > height * float(ratio)
```

### 12.2 新增：`minireader/ui/spread_view.py`（全文 239 行）

```python
"""Mode C: two pages side by side in one view.

`SpreadView` is a plain `QWidget` holding two `PageView`s in a row. It owns no
book and no cache: `ComicReader` hands it a `(first, second_or_None)` pair plus
pixmaps for them, exactly as it does for the single-page and strip modes. All the
"which page goes where" decisions live in `spread.py` as pure functions; this file
only lays widgets out.

Three decisions worth recording:

**Why a shared height rather than two width-fits.** Sizing each page to half the
viewport independently gives two differently-shaped pages two different heights,
so the seam between them is ragged - the one thing that makes a two-page view look
broken. `spread.pair_size()` returns one height for the pair and derives each
width from it, so the bottoms always line up.

**Why the binding is implemented by swapping widgets, not by mirroring.** Right-
binding (右綴じ, Japanese) reads right to left, so the lower page number sits on
the *right*. Swapping the two slots' order is the whole implementation: the page
widgets know nothing about direction, and neither does the layout once it has been
told the order. A lone page takes the leading slot (right for rtl, left for ltr),
which keeps the reading order continuous - a spread always begins at the leading
edge.

**Why there is no scrollbar here.** A spread is a discrete position like single-
page mode, not a continuous scroll like the strip. The reader's `scrollbar()`
answers None in this mode, which is what makes `MiniWindow.toggle_autoscroll()`'s
existing gate refuse it for the right reason - no new code needed, see
`docs/DEVELOPMENT.md`.

The zoom arithmetic lives in `comic_cache.fit_size()` and `spread.pair_size()`,
both pure, so the interesting rules are unit-testable without a QApplication.
"""

from __future__ import annotations

from ..qt import QHBoxLayout, QSizePolicy, QWidget, Qt
from .page_view import PageView
from .spread import pair_size, visual_order

#: Which slot a lone page goes in, per binding: "right" for 右綴じ, "left" for
#: 左綴じ - the leading edge of the reading direction. Kept here (rather than in
#: `spread.py`) because it documents the *widget* mapping; `spread.visual_order()`
#: is the one that actually implements it.
LONE_SLOT = {"rtl": "right", "ltr": "left"}


class SpreadView(QWidget):
    """Two pages side by side, sharing one height."""

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self._pair: tuple[int, int | None] = (0, None)
        self._binding = "rtl"
        self._gutter = 0
        self._zoom = "width"
        self._book = None

        self._row = QHBoxLayout(self)
        self._row.setContentsMargins(0, 0, 0, 0)
        self._row.setSpacing(self._gutter)

        # `_slots[0]` is the LEFT slot, `_slots[1]` the RIGHT one. Which page
        # number each shows is decided per pair by `_order()`, so a lone page in
        # rtl lands in `_slots[1]` without anyone having to move a widget.
        self._slots = [PageView(self), PageView(self)]
        for slot in self._slots:
            # Stretch 0, not 1: `_relayout()` sets an exact width on each slot, and
            # a stretch factor makes the layout override it (measured: a slot pinned
            # to 200 px wide still reported 200, but `setFixedHeight(300)` came back
            # as 800 because the row was distributing the leftover height).
            self._row.addWidget(slot, 0)
            # Ignored/Preferred, not Expanding: "Expanding" is a request to grow,
            # which fights the fixed size `_relayout()` just computed.
            slot.setSizePolicy(QSizePolicy.Preferred, QSizePolicy.Preferred)

        # No focus of its own: the page-turn keys and clicks are handled by
        # ComicReader, which is what the tests drive.
        self.setFocusPolicy(Qt.NoFocus)
        self.setSizePolicy(QSizePolicy.Expanding, QSizePolicy.Expanding)

    # -- content ------------------------------------------------------------

    def bind_book(self, book) -> None:
        """The book whose page sizes this view sizes against.

        Page sizes come from the book (probed in mode B, or from the PDF's page
        boxes), never from a decoded pixmap - the same rule as `StripView`, and for
        the same reason: the layout must not depend on what has been decoded.
        """
        self._book = book
        self._relayout()

    def set_spread(self, pair: tuple[int, int | None]) -> None:
        """Show `(first, second_or_None)`.

        `pair` is in **reading** order - the lower page number first. This method
        applies the binding, so no caller has to think about left versus right.
        """
        first = max(0, int(pair[0]))
        second = None if pair[1] is None else max(0, int(pair[1]))
        self._pair = (first, second)
        left, right = self._order(self._pair)
        self._slots[0].set_page(None, self._label(left))
        self._slots[1].set_page(None, self._label(right))
        self._relayout()

    def set_page(self, index: int, pixmap, message: str = "") -> None:
        """Put one page's image into whichever slot currently shows it.

        Keyed by **page number**, not by slot, so the reader can decode pages in
        any order without having to track where each one landed.
        """
        left, right = self._order(self._pair)
        for slot, shown in ((self._slots[0], left), (self._slots[1], right)):
            if shown is not None and shown == int(index):
                slot.set_page(pixmap, message)
                return

    def clear(self) -> None:
        """Blank both slots."""
        self._pair = (0, None)
        for slot in self._slots:
            slot.clear()

    def _order(self, pair: tuple[int, int | None]) -> tuple[int | None, int | None]:
        """`(left_page, right_page)` for `pair`, honouring the binding."""
        return visual_order(pair, self._binding)

    @staticmethod
    def _label(index: int | None) -> str:
        return "" if index is None else f"第 {index + 1} 页"

    @property
    def pair(self) -> tuple[int, int | None]:
        return self._pair

    def pages_shown(self) -> tuple[int | None, int | None]:
        """`(left_page, right_page)` as currently laid out."""
        return self._order(self._pair)

    @property
    def anchor(self) -> int:
        return self._pair[0]

    def left_slot(self) -> PageView:
        return self._slots[0]

    def right_slot(self) -> PageView:
        return self._slots[1]

    # -- settings -----------------------------------------------------------

    def set_binding(self, binding: str) -> None:
        """rtl (右綴じ: lower page number on the right) or ltr (左綴じ)."""
        binding = binding if binding in LONE_SLOT else "rtl"
        if binding == self._binding:
            return
        self._binding = binding
        # Re-laying out the same pair is what performs the swap; there is no other
        # step, which is the point of implementing the binding this way.
        self.set_spread(self._pair)

    @property
    def binding(self) -> str:
        return self._binding

    def set_gutter(self, pixels: int) -> None:
        """Gap between the two pages, in pixels."""
        pixels = max(0, int(pixels))
        if pixels == self._gutter:
            return
        self._gutter = pixels
        self._relayout()

    @property
    def gutter(self) -> int:
        return self._gutter

    def set_text_colour(self, colour: str) -> None:
        for slot in self._slots:
            slot.set_text_colour(colour)

    def set_zoom(self, zoom: str) -> None:
        """Zoom applies to the *pair*, not per page, so it is remembered here and
        consumed by `_relayout()` through `pair_size()`."""
        self._zoom = zoom
        self._relayout()

    @property
    def zoom(self) -> str:
        return self._zoom

    # -- geometry -----------------------------------------------------------

    def _sizes(self) -> list[tuple[int, int]]:
        """The `(width, height)` of each shown page, in slot order."""
        sizes: list[tuple[int, int]] = []
        for index in self._order(self._pair):
            page = self._book.page(index) if (index is not None and self._book is not None) else None
            if page is not None and page.size_known:
                sizes.append((page.width, page.height))
            else:
                sizes.append((0, 0))
        return sizes

    def _relayout(self) -> None:
        """Recompute the shared height and both widths from the current viewport.

        Arithmetic only - page sizes come from the book, so nothing here decodes
        and nothing here does I/O.
        """
        self._row.setSpacing(self._gutter)
        sizes = self._sizes()
        if not any(size[0] > 0 for size in sizes):
            # Nothing measured yet: split the width evenly and let the heights be
            # the viewport's, so an unm easured book still paints something sane
            # rather than a zero-height pair.
            half = max(1, self.width() // 2)
            for slot in self._slots:
                slot.setFixedWidth(half)
                slot.setFixedHeight(max(1, self.height()))
            return
        height, widths = pair_size(sizes, (self.width(), self.height()), self._gutter)
        for slot, width in zip(self._slots, widths):
            if width > 0:
                slot.setFixedWidth(max(1, width))
            else:
                # A page with no known size gets the other half's width: it shows
                # a "broken page" message, not a zero-width sliver.
                slot.setFixedWidth(max(1, self.width() // 2))
            slot.setFixedHeight(max(1, height))
        self._row.activate()

    def resizeEvent(self, event) -> None:  # noqa: N802 - Qt override
        super().resizeEvent(event)
        # Both pages are sized from the viewport, so a resize changes them. Pure
        # arithmetic again - no decode, no I/O.
        self._relayout()
```

```python
    def _step(self, delta: int) -> None:
        """Move one position, and at an end say so.

        Modes A and B move one *page*; mode C moves one *spread*, which is two
        pages - or one, for the cover and an odd final page. The spec fixes the
        semantics as "下一跨页始终是 index+2", which is exactly what
        `spread.next_anchor()` gives when the anchors step by 2.

        Mode A stays silent at the ends: a single page has nothing to scroll, the
        bottom-bar buttons are already greyed out there, and turning a page at the
        end of the book is not a surprising outcome that needs explaining. Modes B
        and C have a whole book to travel through, so a command that does nothing
        at all reads as a frozen app - there the boundary is announced.
        """
        if self._book is None:
            return
        if self._mode == "spread":
            self._step_spread(delta)
            return
        target = self._book.clamp(self._index + delta)
        if target == self._index:
            if self._mode == "scroll":
                self.say_boundary(-delta)
            return
        self._index = target
        self._render()
        self.scrolled.emit()

    def _step_spread(self, delta: int) -> None:
        book = self._book
        if book is None or not book.pages:
            return
        total = len(book.pages)
        self._resolve_cover_alone()
        target = next_anchor(self._index, total, self._cover_alone, delta)
        if target == self._index:
            # Already at the end in this direction. Mode C announces it - the same
            # rule mode B uses, for the same reason. `delta > 0` means "toward the
            # end of the book", which is `say_boundary`'s -1.
            self.say_boundary(-1 if delta > 0 else 1)
            return
        self._index = book.clamp(target)
        self._render()
        self.scrolled.emit()
```

```python
    def set_mode(self, mode: str) -> None:
        """Switch reading mode.

        Switching modes carries the *page*, not the pixel offset. Going A -> B
        puts the current page at the top of the strip; going B -> A shows
        whichever page was under the middle of the viewport, which is the page
        the bottom bar was reporting. Going A <-> C shows the spread that
        *contains* the current page, because a spread is two pages wide and a
        page number alone does not pick one. Either way the reader does not
        silently move somewhere else.

        Asking for `spread` on a portrait window is refused with a notice, and the
        mode is left alone: two pages side by side in a portrait are each a
        useless sliver. `SPREAD_ASPECT` is the threshold, and it is checked here
        rather than in the caller so that **every** caller - the button, the
        settings dialog, a restored preference, a saved Progress - gets the same
        answer.
        """
        if mode not in READING_MODES:
            mode = READING_MODES[0]
        if mode not in IMPLEMENTED_MODES:
            # A generic sentence on purpose. `MODE_PENDING` used to carry a
            # per-mode "coming in stage N" wording, and stage 5 deleted it once
            # all three modes landed - so there is no table left to look the
            # sentence up in. Leaving a reference to it here was a latent
            # `NameError`: unreachable while `IMPLEMENTED_MODES` covers
            # `READING_MODES`, but armed the moment a future phase adds a mode
            # without implementing it. The exact sentence belongs to the phase
            # that ships the mode; until then any non-empty explanation will do.
            self.notice.emit("这个阅读模式还没做")
            return
        if mode == self._mode:
            return
        if mode == "spread" and not self._spread_fits():
            self.notice.emit("窗口太窄，已切回单页")
            return
        self._mode = mode
        self._stack.setCurrentWidget(self._mode_widget())
        self._render()
        self.viewportChanged.emit()

    def _mode_widget(self) -> QWidget:
        if self._mode == "scroll":
            return self._strip
        if self._mode == "spread":
            return self._spread
        return self._page_view

    def _spread_fits(self) -> bool:
        """True when the reading area is wide enough for two pages.

        Degenerate sizes (0 width or height, before the first layout) count as
        "does not fit": refusing is the safe answer, because entering mode C far
        too early would show two empty slivers and there is no way back except
        the mode button.
        """
        size = self.size()
        return needs_spread_width(size.width(), size.height(), SPREAD_ASPECT)
```

```python
        The pair comes from `spread.py`, which owns every "which page goes where"
        decision (cover alone, lone final page, binding). This method only hands
        the pair to the view and decodes the two pages in it.

        self._preload_timer.stop()
```

```python
    def step_chapter(self, delta: int) -> None:
        """Move one position: a chapter for text, a page for modes A/B, a spread for C.

        Mode C delegates the step to the reader rather than doing the arithmetic
        here. A spread is two pages wide, so `chapter_index + delta` would move by

        spread it already belongs to, so two presses would show the same spread
        (measured: pressing "下一页" four times from the cover reached only the

            # bypasses the reader's `scrolled` signal, so copy it across here too
            # rather than relying on exactly one path.
            self.chapter_index = self.book.clamp(self._comic_reader.index)
            self._update_status()
            self.persist_progress()
```

#### `minireader/core/book_base.py`

`Position.label` 的区间夹取（第 53-68 行）：

```python
    @property
    def label(self) -> str:
        """The bottom bar's left-hand cluster, e.g. "第 3/12 章" or "第 5-6/40 页"."""
        unit = POSITION_LABELS.get(self.kind, POSITION_LABELS[KIND_TEXT])
        total = max(0, int(self.total))
        index = max(0, int(self.index))
        span = max(1, int(self.span))
        if span > 1:
            # Clamp the upper bound to the book. Without this, a two-page spread on
            # the last page of a six-page book reads "第 6-7/6 页" - a page that does
            # not exist. It falls back to the single form, which is the truth: one
            # page is on screen.
            last = min(index + span, total)
            if last > index + 1:
                return f"第 {index + 1}-{last}/{total} {unit}"
        return f"第 {index + 1}/{total} {unit}"
```

## 二、与方案的偏差（1 处，必须说明）

方案 §2.3 写的是 `Reader.show(book)` 和 `Reader.viewport()`。**实现时改掉了这两个名字**，原因实测：

```
>>> hasattr(QWidget, 'show')      -> True    # Qt 自己的
>>> hasattr(QTextEdit, 'viewport') -> True   # Qt 自己的
```

`Reader` 必须排在 MRO **最前面**（否则基类方法被 Qt 盖掉，抽象层形同虚设），
而排在最前面就意味着：基类里任何与 Qt 重名的方法都会**反过来盖掉 Qt 的实现**。
后果是具体的、不是理论的：

- `Reader.show(book)` 一旦生效，`w.show()` 变成 `TypeError: missing 1 required positional argument: 'book'`——Qt 自己要调它。
- `Reader.viewport()` 一旦返回 `None`，`window.py:559` 的 `self.reader.viewport().installEventFilter(self)` 直接 `AttributeError`，连带 `window.py:1843 _edge_surfaces()` 的 4px 边缘缩放和悬停暂停自动滚动一起失效。

所以：

| 方案原文 | 实现 |
|---|---|
| `Reader.show(book)` | **`Reader.show_book(book, *, index, offset, at_end, char_offset)`** |
| `Reader.viewport()` | **不声明**，留给具体阅读器：`ReaderView` 从 `QTextEdit` 继承真的那个，`ComicReader` 自己实现 |

用 `hasattr` 逐个核对过，以下名字在 `QWidget` 和 `QTextEdit` 上都是空的，可以安全使用：
`kind` `show_book` `next_page` `prev_page` `goto` `current_position` `total_positions`
`progress_percent` `scrollbar` `stop` `apply_style`。

`tests/test_book_base.py` 里有两组测试把这件事钉死：
`test_reader_declares_no_qt_owned_name`（34 个 Qt 名字逐个断言不在 `Reader.__dict__` 里）
和 `test_viewport_is_still_qt_own`（断言 `self.view.viewport() is QTextEdit.viewport(self.view)`）。

### 第二个偏差：方法数 6 → 9

方案 §2.3 的表格列了 8 行（`next_page`/`prev_page` 算一行）。实现里 `ReaderView` 追加了 9 个方法，
因为 `apply_style` 在 `ReaderView` 上**早就存在**（`reader.py:111`），不需要转发；
`viewport` 按上面所述不实现。实际追加的是：
`show_book` `next_page` `prev_page` `goto` `current_position` `total_positions`
`progress_percent` `scrollbar` `stop`。

## 三、新增文件全文

### `minireader/core/book_base.py` — 新增：BookBase + Position + 格式常量

```python
"""The shape every book shares, and the one position type the UI speaks.

Two things live here:

1. `BookBase` - the plain base class that `Book` (text) and `ComicBook` (comic)
   both inherit. It is deliberately NOT `abc.ABC`: `Book` is a `@dataclass`, and
   more importantly the reader side of this abstraction (`ui/reader_base.Reader`)
   has to sit in front of Qt widgets, where `abc.ABCMeta` collides with
   `sip.wrappertype` and raises `TypeError: metaclass conflict`. One plain-class
   convention for both sides keeps the rule easy to remember.

2. `Position` - the single progress representation. The bottom bar needs to say
   either "第 3/12 章" or "第 5-6/40 页", and doing that with one frozen value
   object means `_update_status()` needs no if/else on the book kind.

Deliberately Qt-free, like the rest of `minireader.core.*`.
"""

from __future__ import annotations

from dataclasses import dataclass

# The two book kinds. Strings rather than an Enum on purpose: they are written
# into settings.json and progress.json, and a plain string survives a hand edit
# and a downgrade without a migration table.
KIND_TEXT = "text"
KIND_COMIC = "comic"

# What each kind counts, for the bottom bar's "第 x/y ?" suffix.
POSITION_LABELS = {KIND_TEXT: "章", KIND_COMIC: "页"}


@dataclass(frozen=True)
class Position:
    """Where a reader is, in a form both readers can produce.

    `offset` keeps the meaning it already has for text - a scrollbar PIXEL value
    (`core/model.py`'s `Progress` docstring records that decision). Comics leave
    it 0. It is NOT the same thing as `store.Bookmark.offset`, which is a
    chapter-internal character index; those two were kept different on purpose
    (pixels break on a font change, characters do not) and must not be merged.

    `span` is how many positions this one covers: 2 in the two-page comic mode,
    1 everywhere else. It only affects `label()`.
    """

    kind: str = KIND_TEXT
    index: int = 0
    offset: int = 0
    total: int = 0
    span: int = 1

    @property
    def label(self) -> str:
        """The bottom bar's left-hand cluster, e.g. "第 3/12 章" or "第 5-6/40 页"."""
        unit = POSITION_LABELS.get(self.kind, POSITION_LABELS[KIND_TEXT])
        total = max(0, int(self.total))
        index = max(0, int(self.index))
        span = max(1, int(self.span))
        if span > 1:
            return f"第 {index + 1}-{index + span}/{total} {unit}"
        return f"第 {index + 1}/{total} {unit}"

    @property
    def percent(self) -> float:
        """0-100, counting the current position as reached.

        `Book` has always counted this way - chapter 1 of 10 is 10%, not 0% -
        so the text reader's percentage does not change when it starts going
        through here.
        """
        total = max(0, int(self.total))
        if not total:
            return 0.0
        done = min(max(0, int(self.index)) + 1, total)
        return done * 100.0 / total

    def text(self) -> str:
        """`percent` formatted the way the status bar has always shown it."""
        return f"{self.percent:.2f}%"


class BookBase:
    """What the window needs from any book, without knowing which kind it is.

    Subclasses set the class attributes and, where they have the data, override
    the methods. Everything here has a working default so a half-built subclass
    still opens instead of raising in the middle of a paint.
    """

    #: KIND_TEXT or KIND_COMIC.
    kind: str = KIND_TEXT

    #: How many positions this book has: chapters for text, pages for comics.
    #:
    #: The default reads `chapter_count` by duck typing so that `Book` satisfies
    #: this interface without gaining a single new line of its own - `Book`'s own
    #: `chapter_count` property is the answer for a text book, and `ComicBook`
    #: overrides this with `len(self.pages)`.
    @property
    def position_count(self) -> int:
        return int(getattr(self, "chapter_count", 0) or 0)

    #: "章" or "页".
    @property
    def position_label(self) -> str:
        return POSITION_LABELS.get(self.kind, POSITION_LABELS[KIND_TEXT])

    #: True when this book is paged rather than scrolled. The window uses it to
    #: decide which bottom-bar controls make sense, never to branch on format.
    @property
    def is_paged(self) -> bool:
        return self.kind == KIND_COMIC

    def position(self, index: int = 0, offset: int = 0, span: int = 1) -> Position:
        """Build a Position already carrying this book's kind and total."""
        return Position(
            kind=self.kind,
            index=max(0, int(index)),
            offset=max(0, int(offset)),
            total=self.position_count,
            span=max(1, int(span)),
        )

    def describe(self) -> str:
        """One line for the title tooltip. Subclasses override."""
        return f"{self.position_count} {self.position_label}"

    def to_record(self) -> dict:
        """The shelf row written into library.json. Subclasses override."""
        return {}

    @classmethod
    def from_path(cls, path, **kwargs) -> "BookBase":
        """Open `path`. Each subclass implements its own."""
        raise NotImplementedError
```

### `minireader/ui/reader_base.py` — 新增：Reader 接口（普通基类）

```python
"""What the window needs from a reader, without knowing which kind it is.

`Reader` is a PLAIN class - no `abc.ABC`, no `typing.Protocol`, and it must be
listed FIRST in a concrete reader's bases:

    class ReaderView(Reader, QTextEdit):   # 原来: class ReaderView(QTextEdit)
    class ComicReader(Reader, QWidget):    # 阶段 2

All three of those details are load-bearing and were measured, not guessed:

* **No ABC/Protocol.** `QTextEdit`'s metaclass is `sip.wrappertype`, which is not
  a subclass of `abc.ABCMeta`. Writing `class ReaderView(Reader, QTextEdit)` with
  `Reader` an ABC raises `TypeError: metaclass conflict: the metaclass of a
  derived class must be a (non-strict) subclass of the metaclasses of all its
  bases`. `typing.Protocol` fails identically. A plain class has no metaclass of
  its own, so it mixes in cleanly.

* **Base first.** With `Reader` first in the MRO, anything `Reader` defines
  SHADOWS the Qt method of the same name. That is why this class deliberately
  does NOT declare `show()` or `viewport()`:

      class Reader:
          def show(self, book): ...       # ← w.show() then raises TypeError:
                                              missing 1 required positional
                                              argument: 'book'
          def viewport(self): return None # ← window.py:559 does
                                              self.reader.viewport()
                                              .installEventFilter(self)
                                              -> AttributeError: 'NoneType'

  `QWidget.show()` and `QTextEdit.viewport()` are used by Qt itself and by four
  existing tests. So the "open this book" entry point is named `show_book()`,
  and `viewport()` is simply left to the concrete reader: `ReaderView` inherits
  the real one from `QTextEdit`, and `ComicReader` will define its own.

  (Renaming `viewport()` on the comic side instead of declaring it here is what
  keeps `window.py:1843-1849 _edge_surfaces()` and the autoscroll hover-pause
  hook working for both readers.)

Names below were checked against `QWidget`/`QTextEdit` with `hasattr`: `hide`,
`close`, `update`, `repaint`, `resize`, `move` are all Qt-owned and are avoided
for the same reason. `kind`, `next_page`, `prev_page`, `goto`,
`current_position`, `total_positions`, `progress_percent`, `scrollbar`, `stop`,
`apply_style` and `show_book` are free on both bindings.
"""

from __future__ import annotations

from ..core.book_base import KIND_TEXT


class Reader:
    """The interface a reader must satisfy. Bodies raise, deliberately.

    Every method raises `NotImplementedError` rather than returning a neutral
    value: a concrete reader that forgets one should fail loudly in its own
    test, not silently render nothing in the window.
    """

    #: KIND_TEXT or KIND_COMIC. Matches the book this reader renders.
    kind: str = KIND_TEXT

    # ---- content ---------------------------------------------------------

    def show_book(
        self,
        book,
        *,
        index: int = 0,
        offset: int = 0,
        at_end: bool = False,
        char_offset: int | None = None,
    ) -> None:
        """Display position `index` of `book`.

        Named `show_book`, not `show`, because `QWidget.show()` is Qt's own and
        would be shadowed by a base-first mixin (see the module docstring).

        `char_offset` is a chapter-internal CHARACTER index, used when the pixel
        `offset` cannot be trusted (a font change re-wraps the document, so the
        old pixel value points somewhere else). Text readers honour it; a paged
        reader may ignore it.
        """
        raise NotImplementedError

    def apply_style(self, settings) -> None:
        """Re-apply typography/colour after the settings dialog changed them."""
        raise NotImplementedError

    def stop(self) -> None:
        """Release transient state - running animation, image cache, timers.

        Called by the window when it switches to the other reader. Must be safe
        to call when nothing is running.
        """
        raise NotImplementedError

    # ---- paging ----------------------------------------------------------

    def next_page(self) -> None:
        """Advance one position, or one page-worth of scroll in a text book."""
        raise NotImplementedError

    def prev_page(self) -> None:
        """Go back one position."""
        raise NotImplementedError

    def goto(self, position) -> None:
        """Jump to a `Position` produced by `current_position()`."""
        raise NotImplementedError

    # ---- progress --------------------------------------------------------

    def current_position(self):
        """Return a `Position` describing where the reader is now."""
        raise NotImplementedError

    def total_positions(self) -> int:
        """How many positions the current book has."""
        raise NotImplementedError

    def progress_percent(self) -> float:
        """0-100, counting the current position as reached."""
        raise NotImplementedError

    # ---- window integration ---------------------------------------------

    def scrollbar(self):
        """The vertical `QScrollBar` this reader scrolls, or None.

        Returning a real scrollbar is what lets the existing `AutoScroller`
        drive a comic in continuous-scroll mode: it only ever calls `value()`,
        `maximum()` and `setValue()`, and knows nothing about `ReaderView`.
        """
        return None
```

### `minireader/ui/reader.py` 追加的适配层（diff 之外，单独看更清楚）

```python

    # ---- Reader 适配层（阶段 1 新增，纯转发） -----------------------------
    #
    # 上面 431 行既有实现一个字都没动。这一节只是把 ReaderView 已有的能力
    # 按 reader_base.Reader 的接口重新命名，好让 MiniWindow 在阶段 2 之后
    # 能一视同仁地对待文本阅读器和漫画阅读器。
    #
    # 注意：**不要**在这里定义 viewport()。基类放在 MRO 最前，任何同名方法
    # 都会盖掉 Qt 自己的实现，而 window.py:559 要用 self.reader.viewport()
    # 装事件过滤器、window.py:1843 要用它做边缘缩放的判定面。
    # 详见 reader_base.py 的模块说明。

    #: 最近一次 show_book() 交给这本书；类级默认值让访问器在第一次打开书
    #: 之前也是安全的（这样 __init__ 不必新增任何一行）。
    _book = None
    _index = 0

    def show_book(
        self,
        book,
        *,
        index: int = 0,
        offset: int = 0,
        at_end: bool = False,
        char_offset: int | None = None,
    ) -> None:
        """渲染 book 的第 index 章。

        与 MiniWindow.show_chapter() 同义，区别只是把"哪一章"作为参数传进来：
        阅读器自己记下章号，total_positions() / current_position() 才算得出来
        （窗口仍然拥有 self.chapter_index，两边必须保持一致）。

        char_offset 一并转交，好让阶段 2 把 window.py:1600 的 set_chapter() 调用
        换成这里时不会丢掉"按字符还原位置"这条路径（改字体后它比像素可靠）。

        注意：**阶段 1 里 MiniWindow 还在直接调 set_chapter()**，没有走这里，
        所以 _book 仍是 None、current_position() 只会返回 0/0。这是有意的：
        阶段 1 的范围不含 window.py。阶段 2 的第一处改动就是把 show_chapter()
        改成本方法的调用。
        """
        self._book = book
        self._index = book.clamp(index)
        self.set_chapter(
            book.chapter_body(self._index),
            offset=offset,
            at_end=at_end,
            char_offset=char_offset,
        )

    def next_page(self) -> None:
        self.chapterRequested.emit(1)

    def prev_page(self) -> None:
        self.chapterRequested.emit(-1)

    def goto(self, position) -> None:
        if self._book is None:
            return
        self.show_book(self._book, index=position.index, offset=position.offset)

    def current_position(self):
        book = self._book
        if book is None:
            return Position(kind=KIND_TEXT, index=0, offset=0, total=0)
        return Position(
            kind=KIND_TEXT,
            index=self._index,
            offset=self.current_offset(),
            total=book.position_count,
        )

    def total_positions(self) -> int:
        return self._book.position_count if self._book is not None else 0

    def progress_percent(self) -> float:
        return self.current_position().percent

    def scrollbar(self):
        return self.verticalScrollBar()

    def stop(self) -> None:
        """停掉正在跑的滚动动画。没有动画时调用也是安全的。"""
        self._cancel_anim()
```

### 一处诚实的边界

**阶段 2 的第一处改动就是把 `window.py:1600` 改调 `show_book()`**，届时这条路径自然打通，

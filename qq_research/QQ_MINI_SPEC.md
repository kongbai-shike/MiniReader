# QQ 迷你窗规格书（QQ_MINI_SPEC）

> 采集对象：QQ NT 聊天窗口「迷你模式」（标题「迷你窗」，PID 21224，Chrome_WidgetWin_1 / Electron）
> 采集基准：PrintWindow(PW_RENDERFULLCONTENT) 黑底合成图用于颜色/几何采样；屏幕实拍仅用于验证透明效果；部分为用户截图（比例≈1:1，±3%）
> 标注体系：[实测] 直接测量 / [推算] 由实测推导 / [未知] 未采到 / [待确认] 等用户确认
> 透明机制：QQ 用 DirectComposition + NOREDIRECTIONBITMAP；MiniReader 用 Qt WA_TranslucentBackground。**视觉一致即可，不要求底层机制相同。**

## 4. 图标规格（14 个，最终语义）

顶栏 7 个：‹ 上一章(页) / › 下一章(页) / 👁 隐身 / 🎚 透明度 / 📌 置顶 / — 最小化 / × 关闭
- 形状：1.5px 线条图标，字形宽 ~8–17px，命中区间距 44px [实测]
- 置顶为倾斜约 45° 空心图钉，尖尾朝左下 [实测]

第二行工具栏 7 个：‹ 退出（返回 QQ 主界面）/ 已加书架（文字按钮）/ ≡ 目录 / 🌙 暗夜·白昼切换 / Tt 字体设置 / A− 字体变小 / A＋ 字体变大 [实测，语义由用户确认]
- 标签栏附属：书形橙色图标（合成 #c8891a 系）、× 关闭标签、＋ 新建标签 [实测]

## 8. 三阶段改造计划

> 全程遵守项目硬约束：背景只走 paintEvent+QPainter、WA_TranslucentBackground 在 show() 前、移出隐身用 setWindowOpacity(0)、透明度语义统一「不透明度 0-100」、hide→改属性→show 保几何。

### 阶段 1：纯样式对齐（零布局改动，风险最低）

| 改动点 | 文件 | 现状 → 目标 |
|---|---|---|
| 默认窗体底色 | storage.py:142 | #12131a → #1b1b1b |
| 默认背景不透明度 | storage.py | → 60（alpha 153） |
| 圆角 | window.py:101 | BG_RADIUS 10 → 9 |
| 顶栏按钮悬停 | window.py:128-144 | hover 背景块 → 26×26、圆角 ~6px、色 #2d2d2d（按双透明度语义换算） |
| 正文默认色 | storage.py | fg #c9cbd4 → #d8d8da 系 |
| 进度弱化色 | window.py 底栏绘制 | → #67676a 系，字号 ≥11px（用户硬性下限） |
| tooltip | window.py 三键 setToolTip + QSS QToolTip | 底 #262626、字 #9b9b9b、圆角 3px、padding 4×8 |
| 底栏按钮样式 | 底栏按钮 QSS | 翻页钮：1px #6e6e6f 描边、文字 #a3a3a3、圆角 14px、文字 ≥13px、命中区 ≥87×29；目录/设置钮：图标 ≥14px、文字 ≥13px、命中区高 ≥28px、亮度 ≥ 正文 70%（不得弱化）；进度 #67676a 系、字号 ≥11px；底栏高 29–36px、元素垂直居中、间距 ≥8px（可读性优先于「像 QQ」） |
| 设置对话框美化 | settings_dialog.py（仅 QSS/控件属性，不改功能逻辑） | 见下方「设置对话框美化规格」 |

风险：颜色换算进双透明度体系时需区分「源色」，避免二次衰减。测试点：现有 640 条单测全绿；不同 alpha 下按钮文字不衰减。

### 阶段 2：布局调整

| 改动点 | 文件 | 说明 |
|---|---|---|
| 默认尺寸 | storage.py:114 | 480×360 → 397×585（竖长），最小尺寸复核 |
| 顶栏加高 | window.py:396 | 32 → 42px，按钮垂直居中 |
| 底栏重构 | window.py | 左「‹ 上一页」右「下一页 ›」87×29 胶囊钮（映射现有翻页/章逻辑），中间弱化进度 %；目录/设置入口迁入右键菜单或保留为底栏小图标（待定） |
| 正文排版默认 | reader.py / storage.py | 字号默认 ~25px、行距倍数 2.1、缩进 2 字符、每页约 8 行 |
| 进度格式 | 底栏 | 「6.54%」两位小数 |

风险：默认尺寸变更影响老用户存档位置——保留已存 geometry，仅新安装/重置生效；底栏重构涉及现有目录/设置入口迁移，需确认落点。测试点：hide→show 后几何保持；兼容模式（translucent_bg=False）下底栏不崩。

### 阶段 3：交互逻辑

| 改动点 | 文件 | 说明 |
|---|---|---|
| 右键菜单 | window.py/reader.py | 正文区 contextMenuEvent：上一页/下一页｜重新加载本页（样式对齐阶段 1 菜单色板：底 #2b2b2b、字 #bdbdc0、项高 40px、圆角 6px） |
| 滚轮翻页 | reader.py:177 | 可选开关：分页模式下滚轮 → 上/下一页（对齐 QQ「滚轮不滚屏」语义） |
| 悬停 tooltip 文案 | window.py | 👁 随 mouse_leave_hide 状态切换「开启隐身/关闭隐身」；📌 随置顶状态切换 |
| 分页模式 | reader.py | （可选，大改）滚动制 → 分页制；若不做则保留滚动制并在差异表记录 |

风险：滚轮改翻页与现有滚动用户习惯冲突——做成设置项默认关；右键菜单与移出隐身共存时，菜单弹出期间暂停隐身防抖计时。测试点：菜单弹出时窗口不隐身；滚轮开关两态各回归；640+ 条单测全绿。

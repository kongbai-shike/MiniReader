# QQ 迷你窗 · 空态采集摘要（状态 1）

采集时间：2026-10-10。hwnd=0x10b1e（68382），DPI=96，scale=1.0。
采集手段：PrintWindow(PW_RENDERFULLCONTENT) 黑底源图 + 黑/白背景屏幕夹逼 + 像素几何分析 + UIA dump。
脚本接管说明：本阶段**未移动/点击鼠标、未注入键盘**；仅在夹逼时自动创建并销毁了 2 个黑/白背景窗（各显示约 0.8s）。

坐标系约定：
- **B 坐标**：位图坐标，原点 = GetWindowRect 左上，431×620。
- **V 坐标**：可见表面坐标，原点 = 可见表面左上，397×585。
- 夹逼实测可见表面在 B 坐标系中为 (18,18)–(414,602)，即 `GetWindowRect` 四周有约 17–18px 的不可见 DWM 边距。
